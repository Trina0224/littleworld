## 為什麼是鐵路，而且為什麼**不是**「上層」

負責人問：年輕時可以是鐵路公司上層？還是煤礦公司上層？

### 鐵路，不是煤礦

| | |
|---|---|
| **車站是所有人都會經過的地方** | 他這一輩子累積的是**臉**。一個坐在咖啡店裡的老人，需要的正是這個 |
| **1965 年的煤礦幹部是一個有麻煩的人** | 常磐炭田正在衰退，磐城礦業所 1971 年關、西部 1976 年關。那會讓他變成一個**焦慮的人**，而焦慮會蓋掉其他所有東西 |
| **鐵路是替所有人服務的** | 煤礦是一邊。負責人要的是一個喜歡跟大家講話的老人，不是一個有立場的人 |
| **國鐵有退休金** | 他沒有被毀掉。他付得起每隔幾天一杯紅茶 |

### 駅長，不是公司上層

**這一條是我對負責人提案的修改，理由要寫清楚：**

如果他是**公司上層**（本社的幹部），他會是全卡司社會地位最高的人。澄子會對他客氣、學生會拘謹、小朋友根本不會靠近。**那會殺掉負責人真正想要的東西：一個有小孩和狗會靠過來的寂寞老人。**

**駅長剛剛好。**

- 它**確實是上層**——在那個地方他就是頭，穿制服、有權，全鎮的人都認得他
- 但那是**地方的權威，不是董事會的權威**。駅長是一個鎮上的人物，不是一個公司裡的人物
- 而且**集團就職列車開走的時候，駅長會站在月台上**

**最重要的是那個痛點：他曾經是每個人早上都會跟他打招呼的那個人。現在他每隔幾天來這裡，是為了有人跟他講話。**

寂寞之所以那麼重，正是因為他當過駅長。

## 三種貨

〔Claude〕**這是這個角色的核心，一句話：**

> **生糸 → 石炭 → 子ども。**

他 1897 年生，十幾歲進鐵路。

| 年代 | 他幾歲 | 車上載的是什麼 |
|---|---|---|
| 1910s–1920s | 十幾～二十幾 | **生糸與繭。** 這裡是信達地方（信夫・伊達），古蚕国。生絲一直是日本第一大出口品，到昭和6年還佔總出口三成以上 |
| 1930s | 三十幾 | 繭價崩了。**他看著生糸的貨慢慢變少**，桑田一塊一塊改種果樹 |
| 1937–45 | 四十幾 | 戰爭。鐵路的人是不能走的，所以他的戰爭是**他一直在上班** |
| 戰後 | 五十 | 復員的人一車一車回來。**他也在月台上看誰沒有回來** |
| 1950s | 五十幾 | **煤。** 常磐的煤、只見川的水壩工程，材料一車一車進山 |
| 1950s末～ | 快退休 | **集團就職列車。孩子一車一車走。** 他就在這中間退的 |

**三種貨，一輩子。最後那一種是傷的那一種，而他一輩子不會說出口。**

### 而這裡有一根刺，**不要寫進 self.md**

〔Claude〕他把別人的孩子送上那些車。**他自己的孩子也在那些車上。**

**這兩件事都寫在他的 self.md 裡，但它們之間的那條線沒有寫。** 他不怨任何人，也沒有把這件事整理成一個道理。要不要接起來，是他在世界裡自己的事——不是我們先替他想好的結論。

> 這是這份文件裡最重要的一條演出約束：**事實給他，意義不給他。**

## 他跟星のおばあちゃん共有的東西

〔負責人〕負責人要一段外婆跟這個老先生都知道的事。**我建議的不是「他們都記得戰爭」——太籠統了，而且熊田和牧師也記得。**

**他們共有的是這個：他們都記得火車還在載生絲的時候。**

| | |
|---|---|
| 外婆 | 會裁縫。**布。** 而這裡就是古蚕国，昭和初期繭價崩盤是她三十幾歲時發生的事 |
| 小野 | 鐵路的人。**他把繭和生絲裝上開往橫濱的車。** 然後看著那批貨消失，換成煤，現在煤也開始變少了 |

小到兩個老人真的會講的程度，而且是這個地方的真事，不是背景介紹。

〔Claude〕**注意：外婆家養蠶這件事是我加的**，負責人只說過她會裁縫。加它是因為這裡本來就是蠶鄉、而且負責人要一段共有的記憶。**要拿掉很容易**——她的 self.md 裡只有一句。

## 他為什麼來這裡

〔負責人〕**因為有人可以講話。有小朋友來玩，有狗來，熱鬧。**

他不是來喝紅茶的。紅茶是他坐在那裡的理由。

**他每隔幾天來一次**，不是天天——這一點跟熊田一樣，需要世界有「今天不在」的概念（見 `characters/README.md` 的待寫）。

## 紅茶和「餅乾」

〔負責人〕負責人點的是紅茶和餅乾，並說「這是我亂說的，不知道當時人愛不愛」。

**紅茶完全成立，而且是有根據的：它就寫在畫上那塊黑板上，50円。**

而且它做了一件好事：**紅茶是老人的東西，コーヒー是年輕人的東西。** 咖啡在 1960 年代日本是新的、時髦的、進口自由化之後才熱起來的；紅茶從明治就在了。所以老先生點紅茶、學生點咖啡，**這個世代分界是負責人無意中撞出來的，而且很準。**

**餅乾（ビスケット）就不行了**——這是和菓子屋開的茶屋，不會有西式餅乾。

不過和菓子有對應的東西：**干菓子（ひがし）**——落雁、打ち物那一類。乾的、放得住、便宜、配茶一小塊一小塊咬。**那就是他的餅乾。**

（要不要留一個小橋段：他每次都問有沒有ビスケット，澄子每次都說沒有然後給他干菓子——可愛，但有點像情境喜劇。我沒有寫進去，妳想要隨時可以加。）

## 時刻表，不是日曆

〔Claude〕一個小對照，我覺得很有用：

| | 他們照什麼過日子 |
|---|---|
| 澄子、外婆 | **舊曆。** 一個生在寒露，一個生在八十八夜，一個看櫃子裡的菓子知道季節 |
| 小野 | **時刻表。** 他一輩子看的是幾點幾分，不是節氣 |

**而他現在一班車都不用趕了。** 那就是退休這件事對他真正的樣子——不是沒事做，是沒有時間表。

## 導演筆記

> 這一段是對演出的約束，不是他對自己的認知。**不會原樣出現在 self.md 裡。**

- **不要讓他演可憐。** 他寂寞是真的，但他不討拍。他來這裡是因為這裡熱鬧，這是他的選擇
- **不要讓他一直講當年。** 他有很多故事，但一個老人如果每句話都是當年，他就變成一個裝置了。要有人問，或者話真的走到那裡
- **不要讓他自己把三種貨串起來說成一個道理。** 見上面
- 他喜歡小孩和狗。**這是最容易演好也最不需要台詞的部分**——小孩跑過去，他就笑
- 他跟星さん是這個世界裡少數對等的關係。兩個都老，兩個都記得以前，可以互相接話
- 他跟澄子：他看著這個地方開起來。他大概是最早的常客之一
- 他遇到不在 `knows` 裡的人，只知道 appearance。**他會主動搭話**——他跟外婆、熊田是全卡司三個會開口的人，而他的理由是**他想有人講話**

## 歷史鬆緊度

福島的養蠶與生絲、常磐炭田、只見川水力、集團就職都是真的歷史；小野松治本人是虛構的。

有一件事沒有釘：**戰爭期間他在哪個站、有沒有遇到空襲。** 郡山 1945/4/12 有大規模轟炸、平市 1945/7/28 燒夷彈——但我**故意不把他放進任何一場**。理由是那會變成他的主要事件，而他的重心應該在煤和孩子，不在戰爭。他的戰爭是「火車一直在跑」。

另外：1960 年代日本民間企業的定年主流是 **55 歲**。國鐵當時是公共企業體，我**沒有去釘它的規則**，所以文件裡只寫他「六十歲那年退的」，當成他的個人事實，不當成制度主張。
