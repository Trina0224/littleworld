# 卡司

> 給專案負責人、ChatGPT 和 Claude 看的。**任何 LLM 角色都不會讀到這份文件。**

每個角色一個資料夾，格式見 `docs/specs/engine/character-identity.md`。

## 世界事實

> **這一節是這些事實的唯一出處。** 寫新角色之前先讀它，不要重新推導一遍——我已經推導錯過一次了（見下面「姓氏是紀念，不是座標」）。
> 這些是**世界真相**：住在這裡的人全都知道，不需要放進 `knows`。

### 地點

**福島市ひだまり町。**

「町」取**街區**的意思，不是市町村——ひだまり町是福島市裡的一個街區，跟**濱田町**、**森合**同一個層級。這一點不是推論，是畫在背景上的：電線桿上那塊牌子寫著**ひだまり町内会**，而町內會就是街區層級的鄰里組織。

### 這塊地是私有的

**ひだまり公園不是公共公園。整塊地是国分家的**〔負責人〕——就是開喫茶ひだまり那一家，縣內有名的和菓子屋日和堂。

那棵大樹、沙地、滑梯、拱形攀爬架、「ひだまり公園」那塊告示板、還有那道圍牆，**全部是他們家做的**。牆是故意砌成那樣，讓它從街上看起來像一座公園。

這一條解掉了 `AGENTS.md` 開頭記著的那個問題：**原型看了圖說他認不出這是日本，因為他沒看過咖啡店跟公園這樣擺在一起。** 如果那不是公園，是同一塊地，這個反對就不存在了——店連著自己的庭院是再普通不過的日本東西。

而這家店的性質是**展示間**：一間有名的和菓子屋開茶屋，讓人坐下來配抹茶吃自家的練り切り。老舖本來就這樣做。所以菓子漂亮是因為那是商品，有抹茶是因為那配菓子，老闆的女兒站櫃檯是因為展示間放自家人——**而黑板上還有咖啡和紅茶，是因為這是 1960 年代。**

**這件事只有店員知道。** 其他所有人都把這裡當公園。見 `characters/shopkeeper-01/`。

### 菜單（畫上去的，所以是固定的）

```
コーヒー      50円   ← 唯一完全清楚的一行
〔紅茶？〕    50円
〔ミルク？〕  40円
〔認不出來〕  60円
〔認不出來〕  50円
```

**有角色講到價錢時只能講 50 円，不能臨場編。** 品名認不出來的那幾行還沒定，要定的時候照那個價位填。

**吃的只有和菓子，沒有蛋糕**〔負責人〕，而且**店員會當場捏給客人看**（櫃子裡也有現成的）：自家做的**練り切り／上生菓子**——手捏成形、上色、做成季節的樣子，每一個有一個銘（「春霞」「水面」「初雪」這種）。西式蛋糕會跟店員那身和服＋圍裙打架，練り切り不會，而且它多做一件事：**季節換，菓子就換，所以這個世界有了一個時鐘**。那個時鐘握在店員手上。

### 大學

**福島大學**，唯一一個真實存在的專有名詞（因為負責人指定要福島的大學）。當時只有兩個學部，而且分屬兩個校區：

| 學部 | 校區 | 備註 |
|---|---|---|
| 學藝學部 | 濱田町 | 1966 年才改名教育學部 |
| 經濟學部 | 森合 | |

1979 年才合併搬到金谷川。1987 年才增設行政社會學部。

**所以整個世界的專有名詞只有：福島市 / ひだまり町 / 喫茶ひだまり / ひだまり公園 / ひだまり町内会 / 福島大學（濱田町・森合）/ 各家的姓。** 教會刻意還沒命名。

### 年代

**不釘。** 見 `AGENTS.md`：這個地方是用昭和的視覺語言造出來的，不是某一年的重建。

具體一點：畫上的咖啡 50 円查起來大約落在昭和三〇年（1955，東京 1960 年約 60 円、1975 年 150～250 円），而兩個大學生的設定（學藝學部還沒改名、農業基本法之後）落在昭和四〇年（1965）上下。**差了十年，兩個都留著。** 而且那是東京都區部的統計，福島一個町內的街角店便宜一點本來就正常。

### 用詞

- **「過疎」不要出現。** 這個詞要到 1960 年代後半才成為官方用語。要講就講「人越來越少」
- 小孩只用名字（タツ、タタ），大人用姓＋さん，學弟妹用姓＋先輩

## 世界內的關係

這是角色**在世界裡**相信的事，也是 `knows` 的依據。

```
タツ (brother-01, 7, 小二) ─── 兄弟 ─── タタ (brother-02, 6, 小一)
   奧山辰                形影不離         奧山タタ
        └──────── 養的狗 ────────┘
                 ハナ (dog-01, 決定性的腦)

星チヤ / 星のおばあちゃん (grandma-01, 約70) ─── 街坊的長輩，不是兩兄弟的親人
        └── 外孫女 ── ユキ (woman-01, 30)　她只認得外婆一個人
        └── 教會文化教室熟識 ── 森ジョナサン牧師 (pastor-01, 約56)

菅野稔 (boy-01, 21, 福島大經濟四年級) ─ 鄉土研究會的學長學妹 ─ 草野京子 (girl-01, 19, 學藝二年級)
        「草野さん」　　　　　　　　　　友達以上戀人未満　　　　　　　　「菅野先輩」

国分澄子 (shopkeeper-01, 22) ── 日和堂的女兒，喫茶ひだまり是她在管的
        認得：星さん・辰ちゃん・タタちゃん・ハナ・菅野さん　（全部單向）
              ▲
              │ 從小看著她長大。偷偷幫她，也回本舖報告她做得好不好。她不知道
              │
熊田正一 (gentleman-01, 54) ── 日和堂本舖的老員工，快四十年了。不常來
```

**這兩張 `knows` 是同一條規則的相反結果。** 澄子的最長，因為她不走，別人來來去去她累積；熊田的最短（只有一條），因為他不常來，累積得很慢。

**店員的 knows 是全卡司最長的，這是刻意的。** 她是唯一不走的人；別人來來去去，她累積。而且五條全部是單向——外婆叫她「店の子」，小朋友只當她是店裡的姊姊，菅野大概講不出她姓什麼。

**這兩組人互相不認識。** 兩個大學生的 `knows` 裡只有對方，沒有街坊的任何人。他們是坐在同一個空間裡的另一座島。

**おばあちゃん不是兩兄弟的親人。** 小孩叫任何長輩おばあちゃん，那個年代的街坊本來就這樣。

這個決定同時解掉兩個年紀矛盾，值得記下來為什麼：

- 如果她是七歲小孩的祖母，她該是四五十歲，但畫出來明顯七十以上 → 矛盾
- 一旦她**不是**兩兄弟的親人，那個限制就不存在了。她可以是七十歲，跟畫一致
- 而三十歲的孫女需要一個七十歲的祖母 → **正好對上**

一個決定，兩個問題。

> 它寫在這裡是為了讓寫稿的人知道分寸，不是為了演出來。

長裙女這個角色的作者設定是「以三十歲的身分回到這個世界，看看小時候的先生」。**這是作者的位置，不是角色的位置。** 她的 self.md 裡不會有任何一句提到這件事。

### 教會活動的界線

**長裙女與兩個小朋友之間不建立任何關係。** 就是街坊鄰居，僅此而已。

這在規格上有一個具體後果：**她的 `knows` 清單裡不包含兩兄弟。** 所以在她眼中他們永遠是「一個圓滾滾的小男孩」和「一個瘦瘦的小男孩」，不是タツ和タタ——除非哪天在世界裡有人告訴她。

這不需要額外機制，這就是 `character-identity.md` §5 的辨識層在正常運作。

## 姓氏

**要，但只給到必要的程度。**

那個年代的日本，大人之間用姓＋さん互相稱呼。沒有姓氏的話，大人對大人的對白只有兩條路：模型自己現編一個（**而且每個 agent 編得不一樣，世界就破了**），或者避開稱呼、講起來很僵。

所以規則是：

| | |
|---|---|
| 小孩 | **只用名字。** タツ、タタ。那個年代小孩就是這樣被叫的 |
| 大人 | **給姓氏**，因為別的大人會用姓稱呼他們 |
| 姓氏屬於**家戶**，不屬於個人 | 兩兄弟共用一個姓 |
| 不需要的就不給 | 一個從沒跟別的大人講過話的背景角色，不用姓 |

**姓氏必須是虛構的，而且正因為原型是真人。** 用真實家族的姓，等於把這些角色變成對真實人物的主張；用一個普通的虛構姓氏，他們才是角色。

### 選定的姓氏

負責人要求：外婆的姓取自**福島縣**，先生家的取自**山形縣**。以下不是隨手挑的，是查過分布的。

**おばあちゃん：星（ほし）**

福島縣內排第 14 位，全國排第 293 位——**縣內順位比全國高兩百多名**，是真正集中在福島的姓，尤其會津地方。街坊會叫她「星のおばあちゃん」。

而且它對這場活動的觀眾剛好合適：**「星」在繁體中文裡是同一個字、同一個意思**，不用解釋。

其他查到的福島候選：菅野（縣內 6 / 全國 163）、紺野、熊田、国分。円谷雖然是福島中通り最有代表性的姓之一，但跟圓谷英二綁太緊，會把注意力拉走。

**兩兄弟一家：奥山（おくやま）**

山形縣的特徵姓之一。選它的理由是它**普通**——distinctive 到屬於山形，但不會搶戲，適合兩個小學生。繁體中文寫「奧山」，讀得出來，也沒有意外的字面意思。

其他山形候選，如果你想要更有味道的：

| | |
|---|---|
| **最上（もがみ）** | 山形的大河與統治過那裡的氏族，大概是「最山形」的一個姓。味道重一點，也比較顯眼 |
| **土門（どもん）** | 很有辨識度，攝影家土門拳就是山形酒田人 |
| **東海林** | 極有辨識度，但讀作「しょうじ」，讀音跟字面對不上，對這場活動來說是干擾 |

**避開了 我妻（わがつま）**——它確實是山形的特徵姓，但四個中文字讀起來是「我妻」，對中文觀眾會很出戲。

**長裙女**：她是**外**孫女，姓從父親來，本來就跟外婆不同。所以她不姓星——這一點反而是對的，而且安靜地說明了她是來看外婆的人，不是這條街上的人。等真的有大人要稱呼她的時候再給。

**森ジョナサン牧師**：`森` 是這個虛構角色的固定姓氏，不連結任何真實原型或家戶。

**兩個大學生**：他們沒有原型，姓氏純粹是為了讓大人之間的稱呼講得下去，而且要分得出兩個人是從哪裡來的。

|---|---|
| **菅野（かんの）** | 福島縣內排第 6 位、全國第 163 位，中通り的特徵姓。給種田的農家兒子 |
| **草野（くさの）** | 濱通り的特徵姓。給海邊鎮上來的女生。中文寫「草野」乾淨，也不會有奇怪的字面意思 |

### 姓氏是紀念，不是座標

> 這一節是後來補的，因為負責人發現外婆的姓來自福島、兩兄弟的姓來自山形，擔心是設定破洞。**查過之後，它不是。** 理由寫在這裡，免得下次又想一遍。

**第一，奧山根本不是山形限定的姓。**

| | 星 | 奧山 |
|---|---|---|
| 全國 | 第 293 位 | 第 342 位，約 59,800 人 |
| 山形縣內 | — | 第 15 位，約 8,000 人 |
| 福島縣內 | 第 14 位 | 查不到（`myoji-yurai.net` 被 egress proxy 擋住，只能從搜尋結果拿到山形那一列） |

關鍵是那兩個數字相減：**全日本的奧山有八成七不在山形。** 它是「相對集中在山形」，不是「只有山形才有」。在任何地方遇到一戶姓奧山的，都是完全普通的事。

**星就不一樣了**——縣內 14 位對全國 293 位，順位差了兩百多名，那才是真的偏在一個地方的姓。所以兩個姓的「地域性」強度根本不同級，不該放在同一個天平上。

**第二，山形和福島是鄰縣，而且是很近的鄰縣。** 福島市到米沢市直線約 36 公里，中間就是板谷峠，板谷街道（米沢街道）和奧羽本線走了幾百年。這不是搬到天邊。

**第三，也是最重要的一條：這裡的姓氏是負責人選來紀念真實家族的，不是用來標地點的。** 「外婆的姓取自福島、先生家的取自山形」是**作者層**的決定，跟角色住在哪裡是兩件事。一個姓只說明這一戶的來歷，不說明他們現在在哪。

### 這個地方叫ひだまり町

負責人本來就這樣叫它了，所以這裡採用。中文可以寫**日光町**或直接留假名；ひだまり的意思是**曬得到太陽的那個角落**——正好就是畫面上那棵大樹下的公園。

關鍵在**「町」要當成哪一種町**。日文的「町」一詞兩用，這裡取小的那一個：

| | |
|---|---|
| ✗ 市町村的町 | 一個獨立的行政單位，有町長、有町公所 |
| ✓ **地址裡的町** | 市內的一個**街區**，像福島市的**濱田町**和**森合**——上面查學校的時候剛好用到的那兩個 |

**選小的那一個，是因為它讓上面整節的顧慮一次消失。**

- ひだまり町是**福島市**裡的一個街區，跟濱田町、森合同一個層級
- 所以它**本來就在走得到福島大學的距離內**。兩個大學生出現在這家咖啡店，不需要另外解釋
- 世界被釘住的只有「哪一個街區」這個層級。**那個街區是虛構的**，所以沒有任何真實地點被宣稱成這個故事的舞台

> 這裡本來寫的是「那個市不命名，也永遠不需要命名」。負責人後來直接定了：**就是福島大學附近那個市，也就是福島市。** 不命名是我多繞的一步——真正在擋事情的從來不是市名，是街區名，而街區是虛構的。

| 電話亭 / 販賣機 | 公衆電話 / ジュース |

所以這些不是「可以命名」，是**世界真相，而且是每個看得到的人都知道的那一種**。命名這件事負責人在畫圖的時候就做完了，我只是後來才去看。

**電線桿那塊牌子還順手證明了上面那整節的推論。** 上面選「町＝街區」是從福島市的濱田町、森合推出來的；而畫面上寫的是**町内会**——町內會就是街區層級的鄰里組織，不是市町村層級的東西。**畫面本來就是那個意思，我只是繞了一圈才走到同一個地方。**

所以整個世界的專有名詞是：**ひだまり町 / 喫茶ひだまり / ひだまり公園 / ひだまり町内会**（都是虛構，而且都同一個名字——一個街區把名字給了它的公園和它的店，本來就是這樣運作的），加上**福島大學**（真的），加上各家的姓。

### 菜單也是世界真相

店門口的黑板寫著（AI 生成的字有些糊掉了，只有第一行完全清楚，其餘的品名認不出來但價錢讀得到）：

```
メニュー
コーヒー      50円   ← 唯一完全清楚的一行
〔紅茶？〕    50円
〔ミルク？〕  40円
〔認不出來〕  60円
〔認不出來〕  50円
```

**咖啡 50 円查起來大約落在昭和三〇年（1955）**，東京喫茶店一杯咖啡 1955 年約 50 円、1960 年約 60 円、1975 年漲到 150～250 円。而兩個大學生那邊的設定（學藝學部還沒改名、農業基本法之後）是昭和四〇年（1965）上下。**兩個數字差了十年左右。**

這不用修，理由 `AGENTS.md` 早就寫好了：

> The menu board's coffee price does not have to agree with any year's statistics.

而且還有一個更實際的理由：那些數字是**東京都區部**的零售統計。福島一個町內的街角喫茶店比東京便宜，本來就很正常。

**要注意的只有一件事：那塊黑板是畫上去的，所以價錢是固定的。** 哪天有角色要講價錢，講的必須是 50 円，不能臨場編一個。

> 查到但決定不理會的一件事：昭和三〇年代的正式町名幾乎都是漢字，平假名的自治體名要到 1970 年代以後才成風（むつ市 1960 年是頭一個）。不過 `AGENTS.md` 那條「這個地方是想像的，不是重建的」本來就管到這裡——地名是作者的東西，不必送去戶籍謄本上驗。要漢字寫成**日溜町**也可以，但ひだまり暖多了。

## 兩兄弟之間的兩個不對稱

寫完タツ和タタ之後，他們之間有兩件事是各說各話的，而且**方向相反**：

| | タツ 的版本 | タタ 的版本 |
|---|---|---|
| 昨天那條狗 | 他嚇跑了，還說謊 | 我是去找おばあちゃん的，他一直講錯 |
| 畫圖 | 弟弟比我厲害，我承認 | 我畫得比哥哥好，是他自己說的 |

第一件是哥哥佔上風，第二件是弟弟佔上風。**兩件都成立，這對兄弟才不是一個欺負一個。**

## 兩個大學生之間的那個不對稱

同樣的手法，但這一次不對稱**不是誰佔上風，是兩個人往相反方向誤讀同一個沉默**。

去年夏天他們在誤點的巴士站等到天黑，他說了一句他大概會去東京，然後她沒有回話。兩份 self.md 都寫了這件事，寫得不一樣：

| | 菅野稔的版本 | 草野京子的版本 |
|---|---|---|
| 她那天為什麼不講話 | 因為這件事跟她沒關係 | 因為我一句都想不出來 |
| 他後來為什麼不再提東京 | 我識相 | 他已經知道了，他在體貼我 |
| 所以我不說，因為 | 說了會失去現在這個 | 說了會逼他做選擇 |

**兩個人的沉默都是被對方的沉默造成的。誰都沒有錯，誰也不會先動。** 這就是友達以上戀人未満在這裡的機械式定義。

還有一個更小、完全不用台詞的版本：**咖啡錢**。每次都是他付，他覺得先輩付錢天經地義；她已經開始介意，因為只要他一直付，她就一直是後輩。一杯咖啡端上來，誰的手先動。

這個結構能成立的唯一條件，是兩份 self.md 互相不知道對方寫了什麼——跑起來就是兩個 session 各讀各的。這正是 `docs/specs/engine/character-identity.md` §4。

## 兩個大學生念的學校

**福島大學。** 這不是隨手挑的，是查過的：

| | |
|---|---|
| 1949 年 | 由福島師範學校、福島青年師範學校、福島經濟專門學校三校合併成立，**只有學藝學部和經濟學部兩個學部** |
| 1966 年 | 學藝學部改名教育學部（所以在這個世界的時間點，它還叫學藝學部） |
| 1960 年代 | 學藝學部在福島市**濱田町**、經濟學部在**森合**，兩個校區分開。1979 年才合併搬到金谷川 |
| 1987 年 | 才增設行政社會學部 |

這幾件事對角色設定各有用處：

- **只有兩個學部**，所以「同校不同科系」在那個時間點只有一種組合，不用瞎編
- **兩個校區分開**，所以他們不是走廊上會遇到的關係——要見面得有理由，那個理由就是社團。這一條決定了他們的關係怎麼開始
- **學藝學部是師範學校的後身**，所以女生念它、將來當中學老師，在昭和三〇年代的東北是一條清楚而且家裡接受的路

科系也是照那個歷史段落挑的：他念**農業經濟**（1961 年農業基本法之後，農村怎麼活下去是當時真的在吵的題目；加上高度成長期的集團就職與出稼ぎ，東北的年輕人一車一車往東京走），她念**社會科教員養成**。兩個人做的是同一件事的兩半：他下鄉去數，她下鄉去聽。

**「鄉土研究會」這個社團名是杜撰的**〔Claude〕。那個年代大學裡確實有民俗、鄉土、農村調查性質的學生社團，但這一個不對應任何真實社團。

另外有一個詞要看住：**「過疎」要到 1960 年代後半才成為官方用語**，兩個角色嘴裡都不該出現。要講就講「人越來越少」。
