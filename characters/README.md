# 卡司

> 給專案負責人、ChatGPT 和 Claude 看的。**任何 LLM 角色都不會讀到這份文件。**

每個角色一個資料夾，格式見 `docs/specs/engine/character-identity.md`。

## 世界內的關係

這是角色**在世界裡**相信的事，也是 `knows` 的依據。

```
タツ (brother-01, 7, 小二) ─── 兄弟 ─── タタ (brother-02, 6, 小一)
   奧山辰                形影不離         奧山タタ
        └──────── 養的狗 ────────┘
                 ハナ (dog-01, 決定性的腦)

星チヤ / 星のおばあちゃん (grandma-01, 約70) ─── 街坊的長輩，不是兩兄弟的親人
        └── 外孫女 ── ユキ (woman-01, 30)　她只認得外婆一個人
        └── 教會文化教室熟識 ── 森ジョナサン牧師 (pastor-01, 約56)

菅野稔 (boy-01, 21, 福島大經濟四年級) ─ 鄉土研究會的學長學妹 ─ 草野京子 (girl-01, 19, 學藝二年級)
        「草野さん」　　　　　　　　　　友達以上戀人未満　　　　　　　　「菅野先輩」
```

**這兩組人互相不認識。** 兩個大學生的 `knows` 裡只有對方，沒有街坊的任何人。他們是坐在同一個空間裡的另一座島。

**おばあちゃん不是兩兄弟的親人。** 小孩叫任何長輩おばあちゃん，那個年代的街坊本來就這樣。

這個決定同時解掉兩個年紀矛盾，值得記下來為什麼：

- 如果她是七歲小孩的祖母，她該是四五十歲，但畫出來明顯七十以上 → 矛盾
- 一旦她**不是**兩兄弟的親人，那個限制就不存在了。她可以是七十歲，跟畫一致
- 而三十歲的孫女需要一個七十歲的祖母 → **正好對上**

一個決定，兩個問題。

## 作者層

> **這一層永遠不進入世界。** 沒有任何角色知道自己是誰的原型，也沒有任何角色知道有「回到過去」這回事。
> 它寫在這裡是為了讓寫稿的人知道分寸，不是為了演出來。

| 角色 | 原型 |
|---|---|
| タツ | 專案負責人的先生（辰是生肖，不是本名） |
| タタ | 他親弟弟，小他一歲 |
| ハナ | 他們家真的養過的狗，犬種和毛色照實畫 |
| おばあちゃん | 專案負責人的外婆，日本人 |
| 長裙女 | 專案負責人本人，三十歲 |
| 森ジョナサン牧師 | ChatGPT 依角色外型與戰後昭和日本新教會／社區教育語境杜撰的虛構人物，之後可由專案負責人與 Claude 修改 |
| 菅野稔 | 沒有原型。Claude 依角色外型與昭和三〇年代東北大學生的語境全部杜撰 |
| 草野京子 | 同上 |

長裙女這個角色的作者設定是「以三十歲的身分回到這個世界，看看小時候的先生」。**這是作者的位置，不是角色的位置。** 她的 self.md 裡不會有任何一句提到這件事。

### 教會活動的界線

**長裙女與兩個小朋友之間不建立任何關係。** 就是街坊鄰居，僅此而已。

這在規格上有一個具體後果：**她的 `knows` 清單裡不包含兩兄弟。** 所以在她眼中他們永遠是「一個圓滾滾的小男孩」和「一個瘦瘦的小男孩」，不是タツ和タタ——除非哪天在世界裡有人告訴她。

這不需要額外機制，這就是 `character-identity.md` §5 的辨識層在正常運作。

## 姓氏

**要，但只給到必要的程度。**

那個年代的日本，大人之間用姓＋さん互相稱呼。沒有姓氏的話，大人對大人的對白只有兩條路：模型自己現編一個（**而且每個 agent 編得不一樣，世界就破了**），或者避開稱呼、講起來很僵。

所以規則是：

| | |
|---|---|
| 小孩 | **只用名字。** タツ、タタ。那個年代小孩就是這樣被叫的 |
| 大人 | **給姓氏**，因為別的大人會用姓稱呼他們 |
| 姓氏屬於**家戶**，不屬於個人 | 兩兄弟共用一個姓 |
| 不需要的就不給 | 一個從沒跟別的大人講過話的背景角色，不用姓 |

**姓氏必須是虛構的，而且正因為原型是真人。** 用真實家族的姓，等於把這些角色變成對真實人物的主張；用一個普通的虛構姓氏，他們才是角色。

### 選定的姓氏

負責人要求：外婆的姓取自**福島縣**，先生家的取自**山形縣**。以下不是隨手挑的，是查過分布的。

**おばあちゃん：星（ほし）**

福島縣內排第 14 位，全國排第 293 位——**縣內順位比全國高兩百多名**，是真正集中在福島的姓，尤其會津地方。街坊會叫她「星のおばあちゃん」。

而且它對這場活動的觀眾剛好合適：**「星」在繁體中文裡是同一個字、同一個意思**，不用解釋。

其他查到的福島候選：菅野（縣內 6 / 全國 163）、紺野、熊田、国分。円谷雖然是福島中通り最有代表性的姓之一，但跟圓谷英二綁太緊，會把注意力拉走。

**兩兄弟一家：奥山（おくやま）**

山形縣的特徵姓之一。選它的理由是它**普通**——distinctive 到屬於山形，但不會搶戲，適合兩個小學生。繁體中文寫「奧山」，讀得出來，也沒有意外的字面意思。

其他山形候選，如果你想要更有味道的：

| | |
|---|---|
| **最上（もがみ）** | 山形的大河與統治過那裡的氏族，大概是「最山形」的一個姓。味道重一點，也比較顯眼 |
| **土門（どもん）** | 很有辨識度，攝影家土門拳就是山形酒田人 |
| **東海林** | 極有辨識度，但讀作「しょうじ」，讀音跟字面對不上，對這場活動來說是干擾 |

**避開了 我妻（わがつま）**——它確實是山形的特徵姓，但四個中文字讀起來是「我妻」，對中文觀眾會很出戲。

**長裙女**：她是**外**孫女，姓從父親來，本來就跟外婆不同。所以她不姓星——這一點反而是對的，而且安靜地說明了她是來看外婆的人，不是這條街上的人。等真的有大人要稱呼她的時候再給。

**森ジョナサン牧師**：`森` 是這個虛構角色的固定姓氏，不連結任何真實原型或家戶。

**兩個大學生**：他們沒有原型，姓氏純粹是為了讓大人之間的稱呼講得下去，而且要分得出兩個人是從哪裡來的。

| | |
|---|---|
| **菅野（かんの）** | 福島縣內排第 6 位、全國第 163 位，中通り的特徵姓。給種田的農家兒子 |
| **草野（くさの）** | 濱通り的特徵姓。給海邊鎮上來的女生。中文寫「草野」乾淨，也不會有奇怪的字面意思 |

一個內陸、一個靠海，剛好是他們下鄉調查時看的兩種鄉下。**避開了紺野**——它也在福島的名單上，但「菅野／紺野」放在一起，中文讀者第一眼會分不出來。

## 兩兄弟之間的兩個不對稱

寫完タツ和タタ之後，他們之間有兩件事是各說各話的，而且**方向相反**：

| | タツ 的版本 | タタ 的版本 |
|---|---|---|
| 昨天那條狗 | 他嚇跑了，還說謊 | 我是去找おばあちゃん的，他一直講錯 |
| 畫圖 | 弟弟比我厲害，我承認 | 我畫得比哥哥好，是他自己說的 |

第一件是哥哥佔上風，第二件是弟弟佔上風。**兩件都成立，這對兄弟才不是一個欺負一個。**

## 兩個大學生之間的那個不對稱

同樣的手法，但這一次不對稱**不是誰佔上風，是兩個人往相反方向誤讀同一個沉默**。

去年夏天他們在誤點的巴士站等到天黑，他說了一句他大概會去東京，然後她沒有回話。兩份 self.md 都寫了這件事，寫得不一樣：

| | 菅野稔的版本 | 草野京子的版本 |
|---|---|---|
| 她那天為什麼不講話 | 因為這件事跟她沒關係 | 因為我一句都想不出來 |
| 他後來為什麼不再提東京 | 我識相 | 他已經知道了，他在體貼我 |
| 所以我不說，因為 | 說了會失去現在這個 | 說了會逼他做選擇 |

**兩個人的沉默都是被對方的沉默造成的。誰都沒有錯，誰也不會先動。** 這就是友達以上戀人未満在這裡的機械式定義。

還有一個更小、完全不用台詞的版本：**咖啡錢**。每次都是他付，他覺得先輩付錢天經地義；她已經開始介意，因為只要他一直付，她就一直是後輩。一杯咖啡端上來，誰的手先動。

這個結構能成立的唯一條件，是兩份 self.md 互相不知道對方寫了什麼——跑起來就是兩個 session 各讀各的。這正是 `docs/specs/engine/character-identity.md` §4。

## 兩個大學生念的學校

**福島大學。** 這不是隨手挑的，是查過的：

| | |
|---|---|
| 1949 年 | 由福島師範學校、福島青年師範學校、福島經濟專門學校三校合併成立，**只有學藝學部和經濟學部兩個學部** |
| 1966 年 | 學藝學部改名教育學部（所以在這個世界的時間點，它還叫學藝學部） |
| 1960 年代 | 學藝學部在福島市**濱田町**、經濟學部在**森合**，兩個校區分開。1979 年才合併搬到金谷川 |
| 1987 年 | 才增設行政社會學部 |

這幾件事對角色設定各有用處：

- **只有兩個學部**，所以「同校不同科系」在那個時間點只有一種組合，不用瞎編
- **兩個校區分開**，所以他們不是走廊上會遇到的關係——要見面得有理由，那個理由就是社團。這一條決定了他們的關係怎麼開始
- **學藝學部是師範學校的後身**，所以女生念它、將來當中學老師，在昭和三〇年代的東北是一條清楚而且家裡接受的路

科系也是照那個歷史段落挑的：他念**農業經濟**（1961 年農業基本法之後，農村怎麼活下去是當時真的在吵的題目；加上高度成長期的集團就職與出稼ぎ，東北的年輕人一車一車往東京走），她念**社會科教員養成**。兩個人做的是同一件事的兩半：他下鄉去數，她下鄉去聽。

**「鄉土研究會」這個社團名是杜撰的**〔Claude〕。那個年代大學裡確實有民俗、鄉土、農村調查性質的學生社團，但這一個不對應任何真實社團。

另外有一個詞要看住：**「過疎」要到 1960 年代後半才成為官方用語**，兩個角色嘴裡都不該出現。要講就講「人越來越少」。

## 森牧師與星さん

森牧師是星さん參加的教會文化教室裡的牧師之一。兩人已經認識多年，所以 `pastor-01` 的 `knows` 種子包含 `grandma-01`。文化教室有語言、書道、插花、茶道等社區活動；森牧師確實希望藉著教會與人的關係傳福音，但人物設定刻意避免把他做成遇到每個人都立刻傳教的 NPC。完整設定見 `characters/pastor-01/`。
