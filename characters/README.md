# 卡司

> 給專案負責人和 Claude 看的。**任何 LLM 角色都不會讀到這份文件。**

每個角色一個資料夾，格式見 `docs/specs/engine/character-identity.md`。

## 世界內的關係

這是角色**在世界裡**相信的事，也是 `knows` 的依據。

```
タツ (brother-01, 7, 小二) ─── 兄弟 ─── タタ (brother-02, 6, 小一)
   奧山辰                形影不離         奧山タタ
        └──────── 養的狗 ────────┘
                 ハナ (dog-01, 決定性的腦)

おばあちゃん (grandma-01) ─── 街坊的長輩，不是親戚
        └── 孫女 ── 長裙女 (woman-01, 30)
```

**おばあちゃん不是兩兄弟的親人。** 小孩叫任何長輩おばあちゃん，那個年代的街坊本來就這樣。

這個決定同時解掉兩個年紀矛盾，值得記下來為什麼：

- 如果她是七歲小孩的祖母，她該是四五十歲，但畫出來明顯七十以上 → 矛盾
- 一旦她**不是**兩兄弟的親人，那個限制就不存在了。她可以是七十歲，跟畫一致
- 而三十歲的孫女需要一個七十歲的祖母 → **正好對上**

一個決定，兩個問題。

## 作者層

> **這一層永遠不進入世界。** 沒有任何角色知道自己是誰的原型，也沒有任何角色知道有「回到過去」這回事。
> 它寫在這裡是為了讓寫稿的人知道分寸，不是為了演出來。

| 角色 | 原型 |
|---|---|
| タツ | 專案負責人的先生（辰是生肖，不是本名） |
| タタ | 他親弟弟，小他一歲 |
| ハナ | 他們家真的養過的狗，犬種和毛色照實畫 |
| おばあちゃん | 專案負責人的外婆，日本人 |
| 長裙女 | 專案負責人本人，三十歲 |

長裙女這個角色的作者設定是「以三十歲的身分回到這個世界，看看小時候的先生」。**這是作者的位置，不是角色的位置。** 她的 self.md 裡不會有任何一句提到這件事。

### 教會活動的界線

**長裙女與兩個小朋友之間不建立任何關係。** 就是街坊鄰居，僅此而已。

這在規格上有一個具體後果：**她的 `knows` 清單裡不包含兩兄弟。** 所以在她眼中他們永遠是「一個圓滾滾的小男孩」和「一個瘦瘦的小男孩」，不是タツ和タタ——除非哪天在世界裡有人告訴她。

這不需要額外機制，這就是 `character-identity.md` §5 的辨識層在正常運作。

## 姓氏

**要，但只給到必要的程度。**

那個年代的日本，大人之間用姓＋さん互相稱呼。沒有姓氏的話，大人對大人的對白只有兩條路：模型自己現編一個（**而且每個 agent 編得不一樣，世界就破了**），或者避開稱呼、講起來很僵。

所以規則是：

| | |
|---|---|
| 小孩 | **只用名字。** タツ、タタ。那個年代小孩就是這樣被叫的 |
| 大人 | **給姓氏**，因為別的大人會用姓稱呼他們 |
| 姓氏屬於**家戶**，不屬於個人 | 兩兄弟共用一個姓 |
| 不需要的就不給 | 一個從沒跟別的大人講過話的背景角色，不用姓 |

**姓氏必須是虛構的，而且正因為原型是真人。** 用真實家族的姓，等於把這些角色變成對真實人物的主張；用一個普通的虛構姓氏，他們才是角色。

### 選定的姓氏

負責人要求：外婆的姓取自**福島縣**，先生家的取自**山形縣**。以下不是隨手挑的，是查過分布的。

**おばあちゃん：星（ほし）**

福島縣內排第 14 位，全國排第 293 位——**縣內順位比全國高兩百多名**，是真正集中在福島的姓，尤其會津地方。街坊會叫她「星のおばあちゃん」。

而且它對這場活動的觀眾剛好合適：**「星」在繁體中文裡是同一個字、同一個意思**，不用解釋。

其他查到的福島候選：菅野（縣內 6 / 全國 163）、紺野、熊田、国分。円谷雖然是福島中通り最有代表性的姓之一，但跟圓谷英二綁太緊，會把注意力拉走。

**兩兄弟一家：奥山（おくやま）**

山形縣的特徵姓之一。選它的理由是它**普通**——distinctive 到屬於山形，但不會搶戲，適合兩個小學生。繁體中文寫「奧山」，讀得出來，也沒有意外的字面意思。

其他山形候選，如果你想要更有味道的：

| | |
|---|---|
| **最上（もがみ）** | 山形的大河與統治過那裡的氏族，大概是「最山形」的一個姓。味道重一點，也比較顯眼 |
| **土門（どもん）** | 很有辨識度，攝影家土門拳就是山形酒田人 |
| **東海林** | 極有辨識度，但讀作「しょうじ」，讀音跟字面對不上，對這場活動來說是干擾 |

**避開了 我妻（わがつま）**——它確實是山形的特徵姓，但四個中文字讀起來是「我妻」，對中文觀眾會很出戲。

**長裙女**：她是**外**孫女，姓從父親來，本來就跟外婆不同。所以她不姓星——這一點反而是對的，而且安靜地說明了她是來看外婆的人，不是這條街上的人。等真的有大人要稱呼她的時候再給。

## 兩兄弟之間的兩個不對稱

寫完タツ和タタ之後，他們之間有兩件事是各說各話的，而且**方向相反**：

| | タツ 的版本 | タタ 的版本 |
|---|---|---|
| 昨天那條狗 | 他嚇跑了，還說謊 | 我是去找おばあちゃん的，他一直講錯 |
| 畫圖 | 弟弟比我厲害，我承認 | 我畫得比哥哥好，是他自己說的 |

第一件是哥哥佔上風，第二件是弟弟佔上風。**兩件都成立，這對兄弟才不是一個欺負一個。**
