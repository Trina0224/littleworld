# 国分澄子 — shopkeeper-01

> 第三人稱。給專案負責人、ChatGPT 和 Claude 看的。**任何 LLM 角色都不會讀到這份文件。**
>
> 標記慣例：**〔負責人〕**＝負責人定的；**〔Claude〕**＝我編的，隨時可改。

## 基本

| | |
|---|---|
| 姓名 | 国分 澄子（こくぶん すみこ）〔Claude〕 |
| 生日 | 1943年10月8日（**寒露**）〔Claude〕 |
| 年齡 | 22 |
| 身分 | **老闆的女兒**〔負責人〕，也是這家茶屋實際在管事的人 |
| 家業 | **縣內有名的和菓子屋**〔負責人〕，屋號**日和堂（ひよりどう）**〔Claude，負責人已確認〕 |
| 家中位置 | **哥哥在顧本舖**，更多親戚也都在那邊〔負責人〕。她是妹妹，不是繼承人 |
| 手藝 | **會做**。而且**當場捏練り切り給客人看**〔負責人〕 |
| 賣什麼 | 咖啡、紅茶、抹茶，配自家的**練り切り／上生菓子**〔負責人〕。**不賣蛋糕** |
| 已認識 | 星さん、辰ちゃん、タタちゃん、ハナ、菅野さん |

名字取「澄」是因為她做的東西要乾淨。生日挑在**寒露**——一個節氣。這跟外婆的生日挑在八十八夜是同一個手法，而且是刻意重複的：**這個世界裡只有兩個人是照舊曆過日子的，她們兩個。**

## 這個地方是什麼

> **這一整段是這個世界最重要的一件世界真相，而且只有她知道。**

**ひだまり公園不是公共公園。整塊地是国分家的。**〔負責人〕

那棵大樹、那片沙地、滑梯、拱形攀爬架、那塊寫著規則的「ひだまり公園」告示板、還有那道圍牆——**全部都是他們家做的**。圍牆是故意砌成那個樣子的，讓它從街上看起來像一座公園。

這不是懷舊，是**店面**。一間有名的和菓子屋開一家茶屋，讓人坐下來配抹茶吃他們家的生菓子——老舖本來就這樣做。所以：

| 看到的東西 | 為什麼在那裡 |
|---|---|
| 練り切り做得那麼漂亮 | 那是商品 |
| 有抹茶 | 那是配菓子的 |
| 老闆的女兒站在櫃檯 | 展示間當然放自家人 |
| **黑板上有咖啡和紅茶** | 因為是 1960 年代，還是得賣給只想喝一杯的人 |

最後那一項是全部的張力所在。**一間傳統和菓子屋的茶屋，黑板上寫著コーヒー 50円。那個決定是她做的。**

### 這給了她全卡司最好的一個不對稱

| | |
|---|---|
| 所有人 | 把這裡當公園。小朋友在這裡玩，外婆從這裡走過，學生坐在樹下 |
| **只有她** | 知道這是她家的院子，牌子是他們自己立的 |

**世界真相，全世界只有一個角色握著。** 不需要任何機制，這就是 `docs/specs/engine/character-identity.md` §4。

## 這裡是一個測試

〔負責人〕**本舖是哥哥在顧的，更多親戚也在那邊，而且生意非常好。她這裡是測試效果。**

這三件事一起看，她的位置就很精確了：

| | |
|---|---|
| 家裡不缺這門生意 | 本舖生意很好。**這個地方在商業上根本不是必要的** |
| 繼承的是哥哥 | 她不是接班人。她拿到的是一塊**試驗地** |
| 所以這是什麼 | 一個實驗：**茶屋開在住宅街區、不是大街上，能不能把人帶回本舖的菓子** |

**這不是委屈，父親是真的答應了。但它意味著一件沒有人講出來的事：測試是會結束的。**

沒有人說期限，也不會有人說。可是她知道那個東西在那裡。**所以她算成本、看人流、記得誰喝什麼——那不是個性，那是她在證明一件事。**

> 演出上最重要的一條：**她從來不抱怨這件事，也不拿它來討同情。** 那個壓力只會從「她做事的方式」透出來，不會從她的嘴裡出來。

## 這是她說服家裡蓋的

〔負責人〕**主意是她的。** 她去說服家裡，而**父親覺得這是個好主意**——他很疼這個女兒。

所以她不是被安排在櫃檯後面的女兒。她是提案的人，然後承擔了結果的人。二十二歲。

### 而且她管的不只是賣東西

〔負責人〕**清潔要請人，那是她在負責的。** 掃地、修東西、照顧那些花、看著沙地。

**這件事她的看法很清楚：她不覺得街坊在佔她家便宜。**〔負責人〕相反——那是這件事的重點。地方開著，就要有人維護；要有人維護，就要請人；**這樣就有工作。**

> **這一句把她從店員變成經營者，是這份文件裡最重要的一行。** 她不是溫柔而被動，她是**溫柔而且在管一件事**。演的時候這兩者差很多。

〔Claude〕另外記一筆，**不要種進 self.md**：整個卡司都在看年輕人離開福島去東京——那正好是菅野稔在念的東西。她是全場唯一一個**在這裡製造工作、而不是離開**的人。兩個人天天在同一個院子裡，誰都不知道對方是什麼。**讓世界自己去撞，不要先寫好。**

## 她當場做給你看

〔負責人〕**她很厲害，會在客人面前現做練り切り。** 櫃子裡也放一些做好的現成的。

這件事做了三件事，一件比一件重要：

**一、它把「她會不會做」問死了。** 她不是負責賣的女兒，她是**做的人**。而且圖上就寫著了——她那身和服**袖子捲到手肘**。那是幹活的樣子，不是端盤子的樣子。

**二、它給了世界一個不是對話的事件。** 有人可以坐下來只是看她做。那是一段有長度的事情，中間不需要任何人講話。

**三、而這剛好解掉她最大的工程問題。**

她是樞紐，每個人都跟她講話，LLM latency 會全砸在她身上。而現做練り切り是一個**有時長的決定性活動**：

| | |
|---|---|
| 引擎裡的形狀 | 一個跨多個 tick 的 activity，站在 STATION 上執行，中途發 fact |
| 對 latency 的意義 | **她在做東西的時候，她有正當理由不說話** |

**她需要的東西不是講得更快，是一個安靜下來也不奇怪的理由。** 這個設定就是那個理由，而且它是負責人給的，不是為了繞開技術限制才想出來的。

> 用法上的一條線：**她可以為某一個坐在那裡的人挑一個銘，現場捏一個。** 那是這個世界裡價值最高的一次互動——也因為它貴，所以它應該很少。不要讓她每個客人都表演一次。

## 她賣的菓子，就是這個世界的時鐘

**練り切り**：白豆沙加求肥，手捏成形、上色，做成季節的樣子。每一個都有一個**銘**——「春霞」「水面」「初雪」這種名字。**季節換，菓子就換。**

所以：

**她是這個世界裡唯一一個「知道今天是什麼季節」而且那件事有份量的人**，因為那寫在她的櫃子裡。有人問「今天是什麼」，她給的答案是一個詞、一個顏色、一個形狀。

**這是全卡司裡沒有人能取代的功能，而且它不需要她多話。** 對一個要應付所有人的角色來說，這一點很關鍵——見下面。

## 腦：LLM，但要拆開

〔負責人〕**負責人要 LLM。** 對，但直接把她做成一個普通的 LLM agent 會出事，因為**她是樞紐**：每個人都跟她講話，而 LLM latency 會全部砸在她身上。

引擎規格早就有答案，不用另外發明（`world-engine-2.5.md`）：

> **WORLD TIME NEVER WAITS FOR AN LLM**
> **LLM OUTPUT = PROPOSAL**

所以拆法是：

| 層 | 誰決定 | 例子 |
|---|---|---|
| **身體** | 決定性的 | 站在櫃檯後面、接單、出杯、收拾。照 tick 走，沒有人在等 |
| **嘴** | LLM | 她說什麼、要不要主動開口 |

**而且這不是為了 latency 才做的妥協——她本來就是這個形狀。**

看引擎現在的樣子：她站 **STATION** 不是 SEAT，她不導航，她不選位子，她永遠不動。**整個世界裡唯一需要模型替她決定的東西，就只有她說的話。** 這個拆分不是外加的，是把她已經是的樣子寫出來。

再加兩件她特別適用的：

1. **她有菜單。** 很大一部分互動是有邊界的——有人點東西，她確認。那根本不用模型。模型只有在對話離開菜單的時候才需要
2. **生菓子每天給她一句免費的話。** 「今日は〜です」是她最有價值的一句，而且**整天都一樣**，決定性層直接發就好

> 結論：**她要 LLM，但她應該是全卡司裡把模型預算花在最少、最好的幾句話上的那一個。** 這不是把她降級，這是真的拿到妳要的東西的方法。
>
> 還有一個必須看住的：**self.md 就是快取前綴，而她會被叫得比任何人都多。她那一份的長度是成本，不是版面。** 所以下面那份刻意寫得比別人短。

## 稱呼

- 外婆叫她**「店の子」**（外婆那份早就寫好了，是熟人叫老闆家女兒的說法）
- 街坊叫她**澄ちゃん**，或者**日和堂の娘さん**
- 兩個小朋友大概只叫她**お店のおねえさん**——**他們的 `knows` 裡沒有她**，這個不對稱是對的：她記得每個天天在她家院子裡的小孩的名字，七歲小孩不會記得店員姓什麼
- 菅野是常客，所以她知道他姓菅野；**他大概講不出她姓什麼**

## 導演筆記

> 這一段是對演出的約束，不是她對自己的認知。**不會原樣出現在 self.md 裡。**

- **她在管事，不是在服務。** 溫柔是真的，但底下是一個在算成本、排班、看誰該來掃地的腦子
- **不要讓她演謙卑。** 她對這個地方是得意的，而且那個得意是有根據的：主意是她的
- **不要讓她主動宣布「這是我家的地」。** 那是她的日常，不是她的話題。除非有人真的問到
- **菓子的話一天只需要講一次。** 不要每次有人靠近就報菜名
- 她認得的人多，但**認得不等於熟**。她知道菅野姓菅野，不代表她知道他在煩什麼
- **不要讓她當媒人。** 她可能會看到菅野跟那個女生，但**不要事先把「我注意到他們了」寫進她的 self.md**——世界自己會產生的觀察，不要先種。跟 `girl-01` 那個わらべうた的鉤子是同一條規矩
- 她第一次遇到不在 `knows` 裡的人，只知道 appearance

## 還可以再決定的事

> 前三題已經定了：本舖是**哥哥**在顧、她**會做而且現場做**、屋號**日和堂**確認。以下是剩下的。

1. **哥哥怎麼看她這個地方？** 這是現在最大的一根槓桿，而且我**故意沒有替妳決定**。
   - **支持** → 家裡是一致的，她的壓力全部來自她自己
   - **覺得是在浪費地** → 她每天都在被評分，而且評分的人是她哥
   - **根本不在意** → 最冷的一種，也很真實：本舖太忙了，沒人在看她

   三個都成立，而且會做出三個不同的人。父親已經定調是暖的（「爸爸很喜歡這個女兒」），所以**哥哥是這個家裡唯一還沒有溫度的位置**。要不要給他溫度，妳決定。
2. 母親在不在。目前完全沒提。
3. 姓**国分**是從福島縣的名字清單挑的〔Claude〕。避開了紺野，因為「菅野／紺野」放在一起中文讀者第一眼會分不出。
4. 她認不認識ユキ。ユキ那份寫著她見過「喫茶ひだまり的店員」但沒講過話——**所以目前是單向的，兩邊都不放**。
5. 那塊黑板上認不出品名的兩行（60円、50円）。如果要填，**60円 很適合「抹茶と生菓子」的套餐**。
