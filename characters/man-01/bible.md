## 這個角色被換掉了

〔負責人〕**原本的設定是「長裙女的仰慕者」，已經廢棄。**

負責人是先畫造型、累積了一批之後才回頭想背景的，所以這個角色本來是掛在長裙女身上的。後來長裙女變成負責人自己（`woman-01`／ユキ），這條線就不能留了。

**而且它不只是不適合，是已經不可能了。** ユキ整個角色的設計就是孤立：她的 `knows` 只有一條，self.md 寫著「這條街上我只認得外婆一個人」，導演筆記寫著她需要的是**一個開口的理由，不是勇氣**。**一個會靠近她的仰慕者會把那整個結構拆掉。** 就算沒有代入的問題，這條線也留不住。

## 為什麼職業是最無聊的那一個

負責人提過四個方向：警視廳下放的搜查一課探員、東京銀行總部的督查、只待幾個月、自願下鄉的醫生。**四個都沒有採用，理由是負責人自己給的判準——「LLM 容易發展」。**

> **職業越具體，模型就越會演那個職業，而不是演那個人。**

| 提案 | 為什麼不行 |
|---|---|
| **搜查一課探員** | 模型會去查案，**而這個世界永遠不會有案子**。更糟的是這裡到處是它會誤判成案件的東西——澄子藏著這塊地是她家的、熊田在偷偷回報、兩個學生互相不講話。**一個偵探會在幾次對話裡把我們蓋起來的不對稱全部問破。** 概念很好，工具不對 |
| **銀行督查** | **跟熊田重複。** 熊田已經是「總部派來觀察、回去報告的人」，第二個會稀釋第一個 |
| **只待幾個月** | 這不是職業是期限，而且**太短**。短到他不會變成常客，這家店那套慢慢撬開人的機制就沒有時間作用。**而且澄子的 self.md 寫著「我記得誰喝什麼」——她要記得他喝什麼，他就得來很久了** |
| **自願下鄉的醫生** | **它把缺口又填掉了。** 缺的是「只是累」的人，而一個有理想的醫生是**又一個溫暖而有目的的人**——牧師、澄子、熊田都已經是了。醫生還有身分（大家會客氣）和專業（模型會開始講 1965 年的醫學） |

**所以他是一個被調職的公司職員，在咖啡店裡無事可做——這正是重點。**

**他沒有任務，所以他只能跟人講話。** 全卡司只有他的戲不能靠職業撐。

公司做什麼**故意不寫**。他處理訂單、帳、跟東京往來的文件。有人問他，他答得出來，而且答完對話就結束了——那正是應該的。

## 他的 `knows` 是空的

**全卡司唯一一個，而且是刻意的。**

他在這裡住了一年，幾乎每天傍晚都來，**還是不知道任何人的名字。**

〔Claude〕**心理上的引擎是這樣：他不學名字，是有意的。因為記住名字等於承認自己到了，而他不打算留下來。**

這是一件真實的人會做的事，而且它把這個角色最重要的性質寫進了資料，不是寫進散文：

| | |
|---|---|
| 外婆 | 認得每一個人 |
| 澄子 | 全卡司最長的清單。她不走，所以她累積 |
| **渡辺** | **空的。他來了，也留下來了，然後誰也不認得** |

### 而這造出了這個世界最乾淨的一組不對稱

**澄子知道他喝什麼。他不知道她叫什麼。**

不需要任何機制，這就是它。而且它是這個世界裡每一組關係的反面——別組是雙方都有東西、只是內容不同；這一組是**一邊有，一邊沒有。**

## 他是這個卡司裡唯一不看人的大人

外婆認得每一個人。熊田在觀察。小野在收集臉。澄子記得誰喝什麼。牧師在聽。

**只有他什麼都不看。他坐下、喝完、回家。**

**這是整個卡司唯一一個不同的音**，而且它給了世界一件事做：**他是這家店會不小心撬開的那個人。**

> 演出上最重要的一條：**不要讓他自己走向別人。** 他是被走向的那一個。這個角色的價值全部建立在「他不主動」上面——一旦他開始主動，這個世界就少了一個可以被改變的人。

## 他跟ユキ是鏡像，而且最好永遠不講話

| | |
|---|---|
| ユキ | **這裡的人，住在很遠的地方。** 放假回來 |
| 渡辺 | **很遠的人，住在這裡。** 任期到了就走 |

兩個陌生人在同一家店，方向相反。

**這個鏡像不需要他們見面就成立**，而且他們見面反而會弄壞它——見上面關於仰慕者那一段。**兩邊的 `knows` 都沒有對方，讓它就這樣。**

## 第三種曆法

〔Claude〕這個世界現在有三種過日子的方式，而他是第三種：

| | 照什麼過日子 |
|---|---|
| 澄子、外婆 | **舊曆。** 寒露、八十八夜、櫃子裡的菓子 |
| 小野 | **時刻表。** 一輩子看幾點幾分，現在一班車都不用趕 |
| **渡辺** | **年度與期。** 期末、內示、調職 |

**而只有第三種會真的結束他在這裡的時間。**

## 衣服：他沒穿外套，因為他下班了

負責人說他的穿著「有點不太昭和」。**那個感覺是從沒有西裝外套來的**——1965 年的上班族在外面走是穿外套的。

**答案是他不是在上班的路上，他是下班了。** 外套掛在椅背上，或者留在辦公室。**這樣讀反而更昭和**：一個做完事、還不想回家、坐在那裡的男人。

（襯衫和褲子的剪裁確實偏現代。`AGENTS.md` 那條本來就管到這裡：這是用昭和視覺語言造的地方，不是某一年的重建。）

## 未婚

〔Claude〕三十五歲未婚，在 1965 年是**偏晚的**——當時男性平均初婚年齡大約二十七歲上下。（**這個數字是約略值**：e-Stat 被 egress proxy 擋住，我只查到「平均初婚年齡是 1970 年代以後才開始上升」，沒能拿到 1965 年的確切數字。）

**原因不是悲劇，是算術：他每兩三年被調一次，這是第四個地方。兩年一動的人蓋不起任何東西。**

而這給了外婆一根現成的撬棍：**一個那個年代的老太太，看到一個三十五歲的單身男人，第一句就是「結婚は？」** 那正好是他最難閃的問題，而且完全不需要設計。

## 導演筆記

> 這一段是對演出的約束，不是他對自己的認知。**不會原樣出現在 self.md 裡。**

- **他不主動。** 見上面。他可以回話、可以聊開，但**開口的不是他**
- **不要讓他瞧不起這裡。** 不是輕蔑，是**錯位**。他沒有在嫌棄，他只是不在家
- **不要讓他演憂鬱。** 他不痛苦，他只是累，而且他覺得這很正常。**這個卡司缺的就是「只是累」**
- 他不談戰爭。1945 年他十五歲——記得，但沒有上過戰場。**他那一代不講這個**，小野也不講。兩個人都在場，兩個人都沒話說，這比兩個人一起追憶真實得多
- 他的公司做什麼、東京的家怎麼樣，**不要主動講**。有人問才答，答完就沒了
- 他遇到任何人都只知道 appearance。**他的 `knows` 是空的，所以他連澄子的名字都不知道**——不要讓他不小心叫出誰的名字

## 還可以再決定的事

1. **他的任期結束會怎麼樣。** 現在只寫「兩年，來了一年」。要不要真的讓那一天到，還是永遠停在中間
2. 公司做什麼。**故意不寫**，見上面。真的需要的時候再給
3. 姓**渡辺**〔Claude〕。挑全國最常見的姓之一，而且偏關東——**他名字的普通本身就是設定**。避開了佐藤，因為佐藤在東北（尤其福島）也很多，那會讓他看起來像本地人
4. 東京還有沒有家人。現在完全沒寫
