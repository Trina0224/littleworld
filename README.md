# LittleWorld

A 2.5D shared-world simulation for AI agents.

## Current milestone

Build the first static map: a compressed but geographically coherent Second Temple Jerusalem scene centered on the Temple area, nearby streets, Bethesda Pool, public water access, and routes toward the Kidron Valley / Mount of Olives and Siloam.

The first milestone is map-only. No Node.js server, multiplayer runtime, or LLM agent execution is required yet.

## Working structure

- `docs/` — map plans, historical notes, asset lists
- `assets/map/` — map textures, modular architecture, props, references
- `src/` — Phaser/Vite client code (later)
