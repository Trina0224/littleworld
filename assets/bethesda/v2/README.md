# Bethesda asset kit v2

Each PNG contains one reusable 2.5D object. The map keeps all footprints in world meters and adds cast shadows in Phaser.

- `water-neutral.png` — neutral water texture; clipped to projected pool polygons
- `pool-wall-ew.png` — east/west pool wall segment
- `pool-wall-ns.png` — north/south pool wall segment
- `pool-corner.png` — pool corner module
- `pool-stairs-wide.png` — wide pool-access stairs
- `portico-ew.png` — covered east/west portico segment
- `portico-corner.png` — covered corner portico
- `column.png` — individual column

Lighting rule: material shading may remain in the art, but long cast shadows are generated by the renderer toward northwest.
