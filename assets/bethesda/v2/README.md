# Bethesda asset kit v2

Each SVG contains one reusable 2.5D object. SVG was chosen for this pass because it scales cleanly, keeps each object isolated, and avoids the atlas-cropping artifacts seen in v0.6. World footprints remain measured in meters; long cast shadows are generated by Phaser.

- `water-neutral.svg` — direction-neutral water texture clipped to projected pool polygons
- `pool-wall-ew.svg` — east/west pool wall segment
- `pool-wall-ns.svg` — north/south pool wall segment
- `pool-corner.svg` — pool corner module
- `pool-stairs-wide.svg` — wide pool-access stairs
- `portico-ew.svg` — covered east/west portico segment
- `portico-corner.svg` — covered corner portico
- `column.svg` — individual column

Lighting rule: material shading may remain inside an asset, but long cast shadows are rendered toward northwest by the scene renderer.
