# Map Asset Workspace

Planned asset groups:

- `ground/` — limestone paving, packed earth, steps, edges
- `architecture/` — walls, gates, colonnades, stairs, roofs
- `temple/` — Temple-specific modular pieces
- `bethesda/` — pool edges, steps, colonnades
- `market/` — stalls, tables, awnings, baskets, cages, pens
- `water/` — wells, basins, jars, troughs
- `props/` — crates, pottery, benches, lamps, ropes
- `vegetation/` — olive trees, scrub, small planted areas
- `reference/` — visual references and blueprint images

Keep interactive objects separate from baked background art whenever practical.
