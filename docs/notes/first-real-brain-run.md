# 第一次真模型跑出來的對話

喫茶ひだまり，近桌。星のおばあちゃん、辰、渡辺、ハナ 在桌邊，澄子在櫃檯。

每一句都是一個乾淨 context 的模型決定的：它只拿到那個角色的 `self.md`、由 `social`
向量翻出來的行為導引，以及引擎給它的那一份 package。沒有 bible，沒有別人的檔案，
沒有前幾次的請求，也沒有這個世界的真實狀態。

**下面標成截斷的地方，是引擎實際丟掉的字。** 世界收到的是截斷後的那一句。
